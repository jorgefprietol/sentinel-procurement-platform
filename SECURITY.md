# Política de seguridad

No incluyas credenciales, datos personales ni detalles de explotación de sistemas ajenos en issues públicos. Reporta hallazgos de este repositorio mediante [Private vulnerability reporting](https://github.com/jorgefprietol/sentinel-procurement-platform/security/advisories/new).

Incluye versión o commit, componente afectado, pasos reproducibles contra un entorno propio e impacto observado. Los mantenedores evaluarán el hallazgo y documentarán la corrección; no se promete un SLA que no esté respaldado por un servicio operativo.

La configuración pública contiene únicamente ejemplos vacíos. `.env`, reportes de ejecución y secretos generados están excluidos de Git. El proveedor interno de referencia no debe exponerse a Internet.
