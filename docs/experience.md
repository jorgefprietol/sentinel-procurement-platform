# Experiencia técnica demostrable

**Sentinel Procurement — Plataforma de compras con seguridad de APIs y DevSecOps**

Diseño e implementación de una plataforma con servicios equivalentes en C# / ASP.NET Core y Java / Spring Boot, una interfaz React con TypeScript y persistencia PostgreSQL. Incorporación de controles de seguridad de APIs alineados con los diez riesgos de OWASP API Security 2023, incluyendo aislamiento entre organizaciones, autorización por objeto y función, contratos de entrada estrictos, sesiones revocables, límites persistentes y consumo seguro de servicios externos.

Implementación de flujos de compras idempotentes y aprobaciones transaccionales, con cuotas concurrentes y auditoría por organización. Contenerización mediante Docker y Compose, y automatización en GitHub Actions con pruebas de seguridad, recorridos de navegador, análisis estático, evaluación de dependencias e imágenes, SBOM y publicación de artefactos en GHCR.

**Stack:** C#, .NET 10, Java 21, Spring Boot 4, React, TypeScript, PostgreSQL, Docker, NGINX, GitHub Actions, CodeQL, Trivy y Playwright.

**Evidencia:** código público, contrato OpenAPI, pruebas automatizadas y artefactos de cada ejecución del pipeline. Esta descripción corresponde al trabajo implementado en este proyecto; no implica empleo, clientes, certificaciones ni métricas operativas no documentadas.
